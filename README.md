# 图书管理系统序

## 一、铺垫

民国113年9月，参加USTC设计创新实践课程，我被明确了任务：设计一款智能充电APP。

民国114年2月，尝试入门微信小程式，核心语言为Java Script，但四份脚本，关联困难，加上网路羁绊，无奈作罢。

民国114年3月，参加USTC程序设计进阶与实践课程，讲授语言为Java，并习得基于JavaFX库的UI界面方法，以及基于JDBC的数据库操作。

民国114年4月，决定换用Java进行APP开发，借助豆包（原始AI）给APP开头，后续程序仿照形式，自行完成为主。

民国114年6月，APP得到老师好评，被引荐进了计算智能实验室。转战Python语言，投身模型开发。

民国114年11月，硬盘故障，电脑不得不恢复出产设置，原有的APP，凡三千多行代码，以及Java配置，尽数丢失。

民国115年2月，下载Android Studio，自学Android手机APP开发，核心语言为Kotlin，在Gemini（高级AI）的帮助下，成功开发了第一款离线APP：熵算机。

民国115年4月，打算给实验室师兄开发掌上服务器。因课程繁忙，再加上软体Termius做得够多，无奈作罢。

## 二、开工

民国115年9月3日，参加USTC数据库基础课程，得知大作业为开发图书管理系统。

民国115年9月26日，因Java原始配置丢失近一年，重新配置过于麻烦。选择用Python写软体，并发现使用psycopg2库可以不用配置ODBC/JDBC。

民国115年10月6日，现身投入图书管理系统开发工作，使用pyQt5库进行UI渲染，依旧让豆包开头，后续主体工作自行完成。

民国115年10月15日，国庆节仅5天后，电脑主板故障，笔电完全黑屏，只能返厂维修，耗费人民币2809元整，幸好程式主体部分完工，数据没有丢失。

民国115年10月16日，借助实验室工位电脑，完成了最后一个功能：撤销上一步操作，当然只能离线模拟SQL语言。

民国115年10月21日，领回满是补丁的笔电，进行程式收尾。

## 三、完成

民国115年10月23日，大功告成，并且成功打包成了exe文件，真正成为APP该有的样子。同日，所有程式上传至Github。

民国115年10月26日，完成此序。

## 四、尾声

这也许是我本科阶段写的最后一个APP。虽仍有大量想法开发更多的APP，但只能与课程与实验室妥协，无法成为一种课余消遣。
